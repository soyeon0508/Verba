# Reference Document Staging

Store a minimal, high-quality subset of manufacturing knowledge here for the PoC.

Suggested subfolders:
- `specs/` — PDFs or markdown spec sheets for key products.
- `process/` — SOPs, work instructions, change notices.
- `supply-chain/` — lead time policies, safety stock tables, logistics SLAs.
- `faq/` — curated Q&A pairs from service desk tickets.

Compatible formats: PDF, DOCX, XLSX, CSV, Markdown, HTML exports. Keep each file under 10 MB for smooth parsing.
